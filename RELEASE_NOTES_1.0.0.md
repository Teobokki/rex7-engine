## REX 7 ENGINE REAL EX 1.0.0

**WEB** – opens perchance.org inside the app with its own bundled web engine. No separate browser runtime has to be installed.
- Back, Forward, Reload, Home and an address bar
- Logins, saves and settings stay in `%LOCALAPPDATA%\REX 7 ENGINE REAL EX`
- Downloads go to your Downloads folder
- **Import to board** captures the page onto the current REX 7 ELITE frame

**REX 7 ELITE** – an image board with optional animation
- Starts empty. **Upload** opens Downloads. **Bin** clears the board (Ctrl+Z undoes it). **Download** saves a PNG.
- Place, move, scale and rotate images, and use layers (show/hide, opacity, order, duplicate)
- Draw over images with the brush, eraser, fill and colour picker, and set the brush size; undo/redo
- Canvas presets: 1920×1080, 1280×720, 1080×1080, 1080×1920, 800×600, 512×512. Backgrounds: dark, white or transparent.
- **Animation** toggle (off by default) adds the frame timeline (add, duplicate, delete, reorder), onion skin, Play/Loop, a 1–30 FPS setting, and GIF, MP4 and PNG-sequence export
- Projects save as `.rex7`
- Keys: ←/→ frames · Space play · N new frame · Ctrl+Z / Ctrl+Y · V B E G I tools

**Install:** run `REX-7-ENGINE-REAL-EX-Setup-1.0.0.exe` (current user, no admin), or run `REX-7-ENGINE-REAL-EX-Portable-1.0.0.exe` directly, with no install.
